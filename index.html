About GitGlance

A local Git client with Pi AI chat and rich file previews

GitGlance v1.0.0

Open source, local-first, and built for the way you already work with Git.

Review changes, stage and commit, browse branches, tags, stashes, worktrees, LFS files, and submodules, then chat with the Pi agent — all in one window.
